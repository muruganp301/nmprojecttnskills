Access Control Lists (ACLs)

Role-Based Security Model

  • Role Defined: u_incident_workflow_user
  • Create ACL: Users with role can log new tickets via self-service portal
  • Read ACL: Callers can view their own logged tickets; IT staff can view all assigned tickets
  • Write ACL: Assigned technicians and admins can modify state, subcategory, and work notes
  • Delete ACL: Restricted strictly to ServiceNow System Administrators
